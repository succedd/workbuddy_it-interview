高频题目

  • 流水线里单元测试偶发失败（flaky test）卡住合入，如何区分“真 bug”与“不稳定测试”，并给出重试、隔离与 quarantine 的处理策略？中级 · 1 次浏览
  • 数据库变更（DDL / 数据迁移）如何安全地纳入 CI/CD 流水线？如何做“可回滚的数据库发布”（向后兼容、expand-contract、双写回填）避免发布即事故？高级 · 1 次浏览
  • GitLab CI 的 pipeline/stage/job 与 .gitlab-ci.yml 基本结构？中级 · 0 次浏览
  • CI/CD 流水线通常包含 lint→build→test→package→deploy 等阶段，各阶段的“门禁（gate）”有什么作用？为什么要在早期阶段就拦截问题？初级 · 0 次浏览
  • 什么是 CI 里的“制品（artifact）”？为什么构建产物要“不可变、一次构建多处部署”？GitLab CI 中 artifacts 与 cache 有什么区别？中级 · 0 次浏览
  • 如何用流水线实现“多环境逐级发布（dev→staging→prod）”与发布卡点？为什么生产发布前要有手动/自动门禁（manual job / environment）？中级 · 0 次浏览
  • 流水线构建因依赖下载慢、缓存失效频繁超时，如何定位瓶颈（缓存未命中/网络/并发限制），并设计“依赖缓存 + 私有制品库 + 镜像预热”的提速方案？高级 · 0 次浏览
  • 如何设计一个健壮的发布系统？请从「不可变制品 + 环境即代码 + 一键回滚 + 特性开关」四件套说明各自解决什么问题、如何协同。高级 · 0 次浏览
