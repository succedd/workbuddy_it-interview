# Cloudflare Worker 访问统计部署指南

本站自带一个轻量访问统计后端（`cloudflare/worker.js`），部署后可提供：全局访问计数、当日访问、访客国家地理分布、热门城市、热门题目榜。**免费额度完全够用**（Worker 10 万请求/天、KV 10 万读/1 千写/天）。

## 前置条件

- 一个 Cloudflare 免费账号（https://dash.cloudflare.com/sign-up）
- 本机安装 Node.js（≥16）

## 部署步骤

### 1. 安装 wrangler CLI

```bash
npm install -g wrangler
```

### 2. 登录 Cloudflare

```bash
wrangler login
```

浏览器会弹出授权页面，点 Allow 即可。

### 3. 创建 KV 命名空间

```bash
wrangler kv namespace create STATS
```

命令输出中会有一行 `id = "xxxxxxxxxxxx"`，复制这个 id。

### 4. 回填 wrangler.toml

打开本目录下的 `wrangler.toml`，把 `REPLACE_WITH_YOUR_KV_ID` 替换为上一步拿到的 id：

```toml
name = "it-interview-stats"
main = "worker.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "STATS"
id = "你的真实KV_ID"
```

### 5. 部署 Worker

```bash
cd cloudflare
wrangler deploy
```

部署成功后终端会输出 Worker 地址，形如：

```
https://it-interview-stats.<你的子域名>.workers.dev
```

### 6. 前端接入

1. 打开 https://it-interview.is-a.dev
2. 进入管理后台 → 系统设置 → **Cloudflare Worker** 板块
3. 在「Worker 接口地址」填入完整 URL（如 `https://it-interview-stats.xxx.workers.dev`）
4. 保存后即生效——访客每次打开站点自动上报 `/visit`，浏览题目自动上报 `/view?id=题目ID`

## 验证

浏览器访问 `https://你的worker地址/stats`，应返回 JSON：

```json
{
  "total": 123,
  "today": 45,
  "countries": {"CN": 40, "US": 5},
  "cities": {"北京": 20, "上海": 15},
  "topQuestions": [{"id": 1, "title": "...", "views": 30}]
}
```

## 接口说明

| 端点 | 方法 | 说明 |
|------|------|------|
| `/visit` | POST | 上报一次访问（自动识别国家/城市） |
| `/view?id=123` | POST | 上报题目浏览（id 为题目 ID） |
| `/stats` | GET | 获取全部统计数据（JSON） |

- CORS 已配置为 `*`，任何前端域名均可调用。
- 数据存 Cloudflare KV，全球边缘读写、无需自建数据库。

## 与百度统计的关系

两者并存互补：
- **百度统计**：地域/来源/趋势/用户行为分析
- **本 Worker**：全站累计访问数 + 跨访客热门题目榜（百度统计做不到按题目聚合）

## 常见问题

**Q: 部署后 /stats 返回全 0？**
A: 正常——KV 里还没有数据，等有访客触发 `/visit` 后就会有计数。

**Q: 想停用统计？**
A: 站点设置页清空 Worker 接口地址即可，前端不再上报；Worker 本身可保留或 `wrangler delete` 删除。

**Q: 免费额度会超吗？**
A: 10 万请求/天对个人题库站绰绰有余；真超了 Cloudflare 也不会断服务，只是有少量费用（极少见）。
