隐私政策

最后更新：2026-10-26 · 生效日期：2026-10-26

本政策说明你使用 IT面试题库（itinterview.com.cn）时，我们收集哪些信息、为什么收集、保存多久，以及你如何查看、导出和删除这些数据。

一、一句话总结

不登录也能刷题：此时你的收藏、历史、错题只存在你这台设备的浏览器里，不会上传。

登录只是为了让换设备时不丢数据。我们不会出售你的数据，也不会用它做广告投放。

二、我们收集哪些信息

按「你主动给的」和「使用过程中自动产生的」两类分开说：

  • 账号信息：邮箱、昵称（可选）、密码。密码经「加盐 + PBKDF2-SHA256 单向派生」后保存，服务端只存派生结果与随机盐，不保存明文密码，因此我们也无法找回，只能通过邮件重置。
  • 学习数据：收藏的题目、刷题历史（含浏览时间/次数）、错题本与复习进度、每日打卡记录、模拟面试的评分报告。登录后才上传，用于跨设备同步。
  • 你主动提交的内容：投稿的面试题、题目报错反馈（含你填写的联系方式）。投稿会记录提交时的 IP 用于防滥用限流。
  • 访问与设备信息：全站访问计数（累计/当日）、访客所属国家与城市（来自 Cloudflare 请求头，精确到城市级，不含街道或 GPS）、题目浏览计数。这些都是聚合数字，不与你的账号身份绑定。
  • 安全与限流信息：注册/登录/投稿/AI 功能按 IP 记录短窗口计数，用于拦住刷接口；密码重置记录邮箱重置令牌的哈希、IP 哈希与 30 分钟有效期。

三、AI 功能会送出什么内容

请不要在回答里填写真实姓名、手机号、公司内网信息、客户名称或未公开的业务数据。这些内容一旦送出，我们无法从服务商侧撤回。

  • AI 变式题：题目标题、参考答案、所属分类名与标签（用于生成同考点的变式练习）。
  • AI 改卷：题目标题、参考答案，以及你写下的回答（用于按正确性/完整性/表达打分）。
  • 生成结果会被缓存复用：变式题缓存最长 180 天，改卷结果对「同一题 + 同一回答」缓存 7 天；过期自动失效。

四、我们不做什么

  • 不使用广告追踪 Cookie，不接入任何广告联盟或用户画像平台。
  • 不向第三方出售或出租你的个人信息。
  • 不读取你设备上的其它数据；本站只使用自己域名下的浏览器本地存储。

五、Cookie 与本地存储

人机验证（Cloudflare Turnstile）在注册/登录等环节启用，它会按自身策略进行必要校验。

六、信息保存多久

  • 账号与学习数据：保留到你注销为止；注销后按下面的流程删除。
  • 登录令牌：30 天，到期自动失效。
  • 密码重置令牌：30 分钟有效、一次性使用，且只保存哈希值。
  • IP 限流计数：短窗口（分钟级到天级），到期自动淘汰。
  • 访问统计：聚合数字，保留用于观察站点趋势。

七、你的权利

未登录用户的数据只在本机，清除浏览器数据即为删除。若你想让我们处理上述范围之外的请求，可以通过 微信（见「关于本站」页）或 GitHub Issues：github.com/succedd/workbuddy_it-interview/issues 联系我们。

  • 导出我的数据：把云端的收藏、历史、错题与面试报告导出成 JSON 文件下载到本地。
  • 清空云端学习数据：删除云端的收藏、历史与错题记录（保留账号，本机数据不受影响）。
  • 注销账号：永久删除账号，以及云端的学习数据、模拟面试报告、投稿与反馈记录；注销不可撤销，请先导出需要保留的内容。

八、未成年人

本站内容面向求职者与在职工程师。未满 14 周岁的儿童请在监护人陪同下使用；如我们发现在未取得监护人同意的情况下收集了儿童个人信息，会尽快删除。

九、政策更新

本政策随功能调整而更新，更新日期见页首。涉及收集范围、用途或第三方共享的重大变更，我们会在站内显著位置提示。
