如何编写一个最小可用的 systemd .service 单元？请解释 [Unit] / [Service] / [Install] 三段，以及 WantedBy、Restart 等常见字段。

中级简答题系统运维工程师systemdservice单元WantedByRestart开机自启

题目

给出一个能开机自启、崩溃自拉起的服务单元示例，并解释三个段落的职责与关键字段含义。

参考答案

三段结构：[Unit] 描述元数据与依赖排序（Description、After=、Requires=）；[Service] 定义如何启动进程（ExecStart=、Type=、Restart=、User=）；[Install] 定义“启用时如何安装”（WantedBy=multi-user.target 表示开机进入多用户模式时拉起）。

最小示例：[Unit] Description=myapp After=network.target [Service] ExecStart=/usr/bin/python3 /opt/myapp.py Restart=on-failure User=app [Install] WantedBy=multi-user.target，写好后 systemctl daemon-reload && systemctl enable --now myapp 即开机自启并立即启动。

关键字段：Type=simple（默认，ExecStart 即主进程）/forking（后台 fork 需指定 PIDFile）；Restart=no/on-success/on-failure/always 决定退出后是否重启；WantedBy 决定挂在哪个 target 下，enable 实质是在 target.wants 目录建软链。

enable 与 start 的区别：enable 是“登记开机自启（建软链）”，start 是“现在就跑一次”；二者独立，常一起用。
