类加载过程包含哪几个阶段？双亲委派模型是什么，有什么好处？

中级简答题Java后端工程师后端开发工程师类加载双亲委派ClassLoaderGC Roots

题目

考察类生命周期中的加载过程，以及双亲委派模型的工作机制与安全性意义。

参考答案

结论：类加载严格经历“加载→验证→准备→解析→初始化”五步；双亲委派模型让类随加载器具备层次优先级，保障核心类库唯一与安全。

五个阶段

  1. 加载：通过全限定名获取字节流，转为方法区运行时结构，生成 Class 对象。
  2. 验证：校验字节流合法性，确保不会危害虚拟机。
  3. 准备：为 static 变量分配内存并赋零值（final static 常量直接赋真实值）。
  4. 解析：将常量池符号引用替换为直接引用（可延后到初始化后）。
  5. 初始化：执行 <clinit>()（编译器收集类变量赋值与静态块），真正运行 Java 代码。

双亲委派模型

  • 三层加载器：Bootstrap（启动，C++ 实现）、Extension（扩展）、Application（应用）。
  • 工作过程：子类加载器收到请求先委派给父加载器，只有父加载器无法完成时自己才尝试加载。

好处

  • 避免重复加载：同一类只被最顶层的合法加载器加载一次。
  • 安全防篡改：如 java.lang.Object 永远由 Bootstrap 加载，用户自定义同名类无法覆盖核心 API。
  • 核心库一致性：保证基础类在各处行为统一。
