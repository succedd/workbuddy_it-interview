设计一套跨 iOS/Android/Windows 的音视频 SDK，内核与平台层应该怎么分层？采集、编码、传输为什么必须放进内核？

专家系统设计题音视频开发工程师音视频与流媒体工程师架构师SDK架构跨平台音视频

题目

考察跨平台 SDK 架构，要求给出分层边界与接口稳定性论证。

参考答案

要点：

  • 分层：C++ 内核（采集调度、3A 前处理、编解码、传输与拥塞控制、会话管理）加平台适配层（系统摄像头/麦克风/屏幕 API、OpenGL/Metal/Vulkan 渲染、线程与权限），再往外是各语言薄封装（ObjC/Java/C#）。
  • 为什么采集编码传输在内核：三端行为必须一致，且编码参数、码控策略、抗弱网逻辑是 SDK 最核心、最需跨端统一的部分；放进平台层会出现「同样网络 iOS 卡 Android 不卡」的分裂问题。
  • 接口纪律：对外 API 按能力加事件设计（进房/推流/订阅/回调），内核通过抽象接口反向依赖平台能力（摄像头、渲染器），平台实现可替换。
  • 工程要点：内核产出多 ABI 静态库减少分支；平台层吸收权限、后台采集、耳返等系统差异；ABI 稳定期用适配层扛系统升级，避免内核频繁重建。
