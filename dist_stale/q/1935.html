SwiftUI 是什么？它和传统的 UIKit 命令式编程有什么本质区别？

初级简答题移动端开发工程师iOS开发工程师SwiftUI声明式UIKit

题目

考察点：声明式 UI 范式、SwiftUI 与 UIKit 的定位差异。

参考答案

要点：

  • SwiftUI 是声明式 UI 框架：你描述“UI 在不同状态下的样子”，框架负责根据状态变化自动更新界面；而 UIKit 是命令式，需要手动调用代码创建、修改、移除视图（如 addSubview、updateConstraints）。
  • 状态驱动：SwiftUI 以 单一数据源（Source of Truth） 为核心，状态变化通过属性包装器驱动视图重绘；UIKit 常需手动同步视图与模型，易产生状态不一致。
  • 跨平台与组合性：SwiftUI 基于 Swift 的 View 协议用函数式组合构建界面，同一套代码可适配 iOS/macOS/watchOS/tvOS；UIKit 主要面向 iOS/iPadOS。
  • 互操作：SwiftUI 并非完全取代 UIKit，仍可通过 UIViewRepresentable 复用成熟 UIKit 组件，迁移可渐进式进行。
