【编程】用 SwiftUI 写一个支持关键字搜索过滤的联系人列表。

中级编程题移动端开发工程师iOS开发工程师SwiftUIList搜索编程

题目

考察点：@State 绑定、List 渲染、过滤逻辑与双向绑定。

参考答案

要点：

  • 用 @State private var searchText 持有搜索词，并用 @State private var contacts 持有数据源；TextField 通过 $searchText 双向绑定输入。
  • 用 filtered 计算属性按 searchText 过滤（不区分大小写包含匹配），List 遍历 filtered 渲染每行。
struct ContactListView: View {
    @State private var searchText = ""
    @State private var contacts = ["Alice", "Bob", "Charlie", "David"]

    var filtered: [String] {
        searchText.isEmpty ? contacts : contacts.filter {
            $0.localizedCaseInsensitiveContains(searchText)
        }
    }

    var body: some View {
        NavigationStack {
            List(filtered, id: \.self) { name in
                Text(name)
            }
            .searchable(text: $searchText, prompt: "搜索联系人")
            .navigationTitle("联系人")
        }
    }
}
  • 讲解：.searchable 提供系统搜索栏并绑定到 searchText；filtered 是派生值，输入变化时 SwiftUI 自动刷新 List。生产可把 contacts 换成 @StateObject 从网络加载，并加 onChange 做防抖搜索。
