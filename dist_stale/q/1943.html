Nuxt 的约定式目录结构是怎么工作的？pages、components、app.vue、composables 各自作用？

中级简答题前端开发工程师全栈开发工程师Nuxt目录结构自动导入路由

题目

考察点：Nuxt 文件约定、自动路由与自动导入机制。

参考答案

要点：

  • pages/：目录下的 .vue 文件按路径自动生成路由（如 pages/about.vue → /about），无需手写 router 配置；app.vue 是应用根组件，通常放 <NuxtPage /> 出口。
  • components/：组件自动导入，无需 import 即可在模板使用（如 components/MyCard.vue → <MyCard />）；支持按目录前缀分组。
  • composables/：组合式函数自动导入（如 useCounter()），遵循 use* 命名约定，支持服务端/客户端共享逻辑。
  • 自动导入原理：Nuxt 启动时扫描约定目录生成 import 映射（基于 unimport），减少样板代码；可在 nuxt.config.ts 配置关闭或扩展。
  • 其他：layouts/ 布局、plugins/ 插件、server/ 服务端 API 路由、assets/ 与 public/ 静态资源。
