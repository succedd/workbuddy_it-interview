用 sentence-transformers 把文本转成向量并写入 FAISS，再按相似度检索 top-k，请写出可运行代码并讲解关键参数。

中级编程题算法工程师后端开发工程师RAGEmbeddingsentence-transformersFAISS向量检索

题目

考察点：掌握 embedding 生成与向量检索的最小可运行实现，理解 model、normalize_embeddings、index 选型等关键参数。

参考答案

要点：

  • 生成向量：用 sentence-transformers 的 encode，开启 normalize_embeddings=True 让余弦相似度等价于内积，检索更稳定；中英文选多语言模型（如 paraphrase-multilingual-MiniLM 或 bge 系列）。
  • 建库与检索：FAISS 的 IndexFlatIP（内积）配合归一化向量即余弦检索，简单场景够用；量大再换 IVF/PQ 近似索引降延迟。
  • 关键参数：batch_size 控制显存；top_k 决定召回候选数（通常 3–10）；k 越大召回越全但噪声越多。
from sentence_transformers import SentenceTransformer
import faiss, numpy as np

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
docs = ['RAG 用检索增强生成', 'K8s 负责容器编排', 'MySQL 索引加速查询']
q = '什么是检索增强生成？'

emb_docs = model.encode(docs, normalize_embeddings=True, batch_size=32)
emb_q = model.encode([q], normalize_embeddings=True)
index = faiss.IndexFlatIP(emb_docs.shape[1])
index.add(np.asarray(emb_docs, dtype='float32'))
scores, idx = index.search(emb_q.astype('float32'), k=3)
print([docs[i] for i in idx[0]])  # 余弦相似度最高的前 3 段
  • 讲解：normalize_embeddings=True 后内积=余弦；IndexFlatIP 是精确检索，上线前用它验证召回上限，再按需切换到近似索引降延迟与显存。
