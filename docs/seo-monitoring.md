# 搜索收录监控

## 一次性接入

1. Google Search Console：添加资源 `https://itinterview.com.cn/`，按页面提示完成 DNS 验证。
2. 百度搜索资源平台：添加站点 `https://itinterview.com.cn/`，完成 HTML 标签或 DNS 验证。
3. 两个平台都提交 `https://itinterview.com.cn/sitemap.xml`，并开启自动抓取。

## 每周记录

每周一记录一次，保存在本文件下方：

- Google：覆盖率、展示次数、点击次数、Top 查询、Top 页面。
- 百度：索引量、抓取异常、点击量、Top 查询。
- 重点页面：`/`、`/questions`、`/quiz`、`/q/1.html`、代表性 `/c/*.html` 与 `/p/*.html`。
- 异常：未收录页面、流量下降页面、sitemap 校验错误。
