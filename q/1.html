Java 中 == 和 equals 的区别是什么？

初级简答题Java开发工程师Java后端工程师Java基础equals对象

题目

请说明基本类型与引用类型在使用 == 与 equals() 时的行为差异，并解释为什么 String 的等值比较要用 equals。

参考答案

== 比较的是值：

  • 对于基本类型（int、double 等），比较的是字面量是否相等；
  • 对于引用类型，比较的是对象的内存地址（是否为同一个对象）。

equals() 是 Object 类的方法，默认实现等价于 ==（比较地址）。但很多类（如 String、Integer、List）重写了它来比较逻辑内容。

为什么 String 用 equals：字符串常量池会导致不同方式创建的字符串地址不同，但内容可能相同。例如 new String("a") == "a" 为 false，而 .equals("a") 为 true。因此判断字符串内容相等必须用 equals()，且建议写为 "常量".equals(变量) 以规避空指针。
