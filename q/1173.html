单选题：关于 Vue3 中 ref 与 reactive 的使用，下列说法正确的是？ A. reactive 可以直接用于基本类型（数字/字符串） B. ref 在模板中使用时必须写 .value C. ref 用于基本类型、reactive 用于对象；ref 在模板中会自动解包，无需 .value D. reactive 对象被整体重新赋值仍保持响应式

中级单选题前端开发工程师Vue3refreactive单选题

题目

考察点：ref 与 reactive 的选用规则与模板解包行为。要能判断每个选项对错并讲清理由。

参考答案

正确答案：C

  • A 错：reactive 只接受对象/数组/Map/Set 等引用类型，传基本类型会报警告且失去响应式；基本类型必须用 ref。
  • B 错：ref 在 JS 逻辑里要用 .value 访问，但在模板中会自动解包，直接写 {{ count }} 即可，无需 .value。
  • C 对：这是官方推荐分工——基本类型用 ref、对象用 reactive；ref 在模板自动解包是编译期处理的（前提是 ref 是顶层属性，嵌套在 reactive 里也会解包）。
  • D 错：reactive 整体重新赋值（state = {…}）会断开原代理引用、丢失响应性；正确做法是用 Object.assign(state, newObj) 原地合并，或改用 ref 包一层用 .value 替换。

选型口诀：「基本用 ref，对象用 reactive；要替换整对象就 ref 包一层」。
