两条规则同时命中一个元素，浏览器最终用哪一条？请说明 CSS 优先级的计算规则，以及 !important 在整个体系里的位置。

中级简答题前端开发工程师HTML/CSS/JS工程师页面重构工程师CSS选择器优先级层叠important

题目

考察点：层叠（cascade）与选择器权重，以及 !important 的代价认知。

参考答案

优先级是权重，不是先后。MDN 指出：当一个元素有多个声明时，浏览器用「优先级」判断哪条最相关；只有当优先级相等时，才比较出现顺序，后定义的生效。

权重从低到高：

  1. 类型选择器 / 伪元素（h1、::before）
  2. 类、属性选择器、伪类（.box、[type=radio]、:hover）
  3. ID 选择器（#app）

可以记成三元组 (ID, class, type)：div#test span = (1,0,2)，胜过 div span = (0,0,2)。

不影响优先级：通配符 *、关系选择器（+ > ~ 空格 ||）、以及 :not() / :is() 本身；但括号内部的选择器照常计入。:where() 则把内部优先级清零（0-0-0）。

特殊层：行内样式（style='...'）优先级最高，覆盖所有外部样式表，但仍低于 !important；!important 与优先级无关却结果最高，MDN 明确称之为坏习惯——它破坏级联、让调试变难，只建议用于「覆盖第三方库或内联样式」这种特定场景。

两个易错点：

  • 优先级只看选择器形式，无视 DOM 距离：*[id=foo] 按属性选择器算 (0,1,0)，输给 #foo。
  • 直接命中永远赢继承：即使 #parent{color:green} 权重更高，h1{color:purple} 依然作用在 h1 上，因为继承来的样式优先级最低。

实践：用 BEM 之类命名把权重控制在单层，避免层层叠加选择器；确需覆盖时优先提升选择器特异性，而不是加 !important。
