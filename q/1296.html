CSS Grid 相比 Flex 多了哪些能力？请用 grid-template-columns、minmax()、repeat() 说明如何实现一个不需要媒体查询的自适应卡片网格。

中级简答题前端开发工程师页面重构工程师UI/UX设计师CSSGridFlex响应式布局

题目

考察点：一维/二维布局的选型，以及 Grid 核心语法的实际运用。

参考答案

定位差异：Flex 是一维布局（沿一行或一列排布），Grid 是二维布局，能同时按行和列对齐元素，甚至让子项重叠、像定位元素那样分层。

核心概念（MDN 术语表）：网格线（grid lines）、网格轨道（grid tracks）、网格单元格（grid cell）、网格区域（grid areas）、间隙（gutters）。

基础写法：

.wrapper{
  display:grid;
  grid-template-columns:repeat(3,1fr);   /* 3 条等宽列轨道 */
  gap:10px;
  grid-auto-rows:minmax(100px,auto);       /* 行高最小 100px，内容多则自动撑高 */
}
.card{grid-column:1 / 3;grid-row:1 / 3}    /* 按网格线范围跨列、跨行 */
  • repeat(3,1fr) 生成 3 条等宽轨道，1fr 表示平分剩余空间；
  • minmax(100px,auto) 给出行高下限与自适应上限，fit-content() 让轨道按内容收缩；
  • 子项用 grid-column / grid-row 按网格线区间定位，可跨行跨列。

自适应卡片网格（强烈推荐）：

.cards{
  display:grid;
  gap:16px;
  grid-template-columns:repeat(auto-fill,minmax(240px,1fr));
}

auto-fill / auto-fit 会根据容器宽度自动决定列数，每列不小于 240px、再等分剩余空间——一行代码实现响应式，不需要媒体查询。

选型经验：整页骨架、二维卡片墙、需要行列同时对齐时用 Grid；单行导航条、工具栏、按内容伸缩的一维排列用 Flex。两者可自由嵌套：Grid 容器的子项本身也可以是 Flex 容器。
