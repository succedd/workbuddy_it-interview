Java 内存模型（JMM）的三大特性是什么？volatile 与 synchronized 有什么区别？

中级简答题Java后端工程师后端开发工程师JMMvolatilesynchronized可见性原子性有序性

题目

考察 JMM 的原子性、可见性、有序性，以及 volatile 与 synchronized 各自能解决的问题。

参考答案

结论：JMM 围绕原子性、可见性、有序性三大特性；volatile 保证可见性和有序性但不保证原子性，synchronized 三者兼保但开销更大。

JMM 三大特性

  • 原子性：一个操作不可分割、不可中断（如 synchronized、CAS、Atomic*）。
  • 可见性：一个线程修改共享变量，其他线程能立即看到（如 volatile、synchronized、final）。
  • 有序性：程序执行顺序符合预期，禁止可能影响结果的指令重排（volatile 内存屏障、synchronized 串行临界区）。

volatile 的能力与局限

  • 通过写回主内存 + 读前从主内存刷新保证可见性；通过内存屏障禁止重排序保证有序性。
  • 不保证原子性：如 i++（读-改-写）在多线程下用 volatile 修饰仍可能丢失更新，必须靠锁或 AtomicInteger。

volatile vs synchronized

| 维度 | volatile | synchronized |

| :--- | :--- | :--- |

| 原子性 | 不保证 | 保证 |

| 可见性 | 保证 | 保证 |

| 有序性 | 禁止重排 | 临界区串行化 |

| 阻塞 | 不阻塞 | 可能阻塞 |

| 适用 | 状态标志、双重检查锁 | 复合操作、临界区 |

面试要点：volatile 适合“一写多读”的标志位场景，不能替代锁解决所有并发安全问题。
