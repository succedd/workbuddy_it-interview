JVM 运行时数据区域分为哪些部分？哪些是线程私有、哪些是线程共享？

中级简答题Java后端工程师后端开发工程师JVM内存模型运行时数据区堆元空间虚拟机栈

题目

考察 JVM 内存布局，以及各区域的作用、是否共享和会抛出的异常。

参考答案

结论：JVM 内存分为线程私有区（程序计数器、虚拟机栈、本地方法栈）和线程共享区（堆、方法区/元空间）；私有区随线程生灭无需 GC，共享区是 GC 和 OOM 的主战场。

线程私有区

  • 程序计数器：记录当前线程执行的字节码指令地址；唯一不会 OOM 的区域。
  • Java 虚拟机栈：每调用一个方法创建栈帧（局部变量表、操作数栈等），-Xss 控制大小；深度过大抛 StackOverflowError。
  • 本地方法栈：为 Native 方法服务，类似虚拟机栈。

线程共享区

  • 堆（Heap）：对象实例与数组分配地，是 GC 主要区域，分新生代/老年代；-Xms/-Xmx 控制大小，不足抛 OutOfMemoryError。
  • 方法区/元空间：存放类信息、常量、静态变量、即时编译代码。JDK 8 起移除永久代，改用元空间（Metaspace），位于本地内存，降低 PermGen OOM 风险。

对比

| 区域 | 是否共享 | 主要异常 |

| :--- | :--- | :--- |

| 程序计数器 | 私有 | 无 |

| 虚拟机栈 | 私有 | StackOverflowError / OOM |

| 堆 | 共享 | OutOfMemoryError |

| 元空间 | 共享 | OutOfMemoryError |
