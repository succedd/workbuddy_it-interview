如何设计并实现一个 O(1) 的 LRU 缓存？说明数据结构与淘汰策略

中级简答题后端开发工程师前端开发工程师LRU哈希表双向链表

题目

考察哈希表与双向链表组合、容量淘汰策略

参考答案

核心结构

  • 用哈希表做 O(1) 定位节点，用双向链表维护使用顺序（头=最近使用，尾=最久未用）。
  • 访问或插入节点时移到表头；超过容量时删除表尾节点，并从哈希表移除。

复杂度

  • get 与 put 均为 O(1)。

代码（JavaScript，借助 Map 保序）

class LRUCache {
  constructor(capacity) { this.cap = capacity; this.map = new Map(); }
  get(key) {
    if (!this.map.has(key)) return -1;
    const v = this.map.get(key);
    this.map.delete(key); this.map.set(key, v); // 提到最新
    return v;
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.cap) {
      const oldest = this.map.keys().next().value;
      this.map.delete(oldest); // 淘汰最久未用
    }
  }
}

JavaScript 的 Map 会保留插入顺序，删除再插入即可把节点置为最新，迭代首键即最久未用，从而省去手写双向链表。
