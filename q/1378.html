如何计算 Cache 的平均访问时间？写直写（Write-Through）与写回（Write-Back）、写分配与非写分配有什么区别？

中级简答题系统软件工程师后端开发工程师Cache命中率平均访问时间写直写写回写分配

题目

考察命中率/平均访问时间公式（含串行与并行两种访问模型），以及 Cache 与主存一致性的写策略选择与组合。

参考答案

一、平均访问时间

设命中率 H、Cache 访问时间 Tc、主存访问时间 Tm。题目分两种模型，务必看清题意：

  • 串行模型（先查 Cache，未命中再访存）：T_avg = H×Tc + (1-H)×(Tc + Tm)，未命中时额外耗费一次 Cache 访问 + 主存访问。
  • 并行模型（Cache 与主存同时查，命中则弃主存结果）：T_avg = H×Tc + (1-H)×Tm，平均耗时更低。

计算示例：Tc=5ns, Tm=100ns, H=95%，串行模型 T_avg = 0.95×5 + 0.05×105 = 4.75 + 5.25 = 10ns；H 提升到 98% 则 T_avg = 0.98×5 + 0.02×105 = 4.9+2.1 = 7ns。

二、写策略（处理 Cache 命中时写）

  • 写直写（Write-Through）：同时写入 Cache 和主存，主存始终最新，一致性好但每次写都访问主存、效率低。
  • 写回（Write-Back）：只写 Cache，并将该行标记「脏(Dirty)」，仅当该行被替换时才写回主存，效率高，但存在 Cache 与主存不一致的时间窗口。

三、写不命中策略

  • 写分配（Write-Allocate）：写不命中时先把对应块调入 Cache 再写，通常配合写回使用。
  • 非写分配（No-Write-Allocate / Write-Around）：写不命中时直接写主存、不调入 Cache，通常配合写直写使用。

四、一致性补充：多核下各核私有 Cache 还需 MESI 等一致性协议维护；仅组相联/全相联才需要替换算法（FIFO/LRU/RAND），直接映射无需替换选择。
