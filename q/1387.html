单周期 CPU 的数据通路（Data Path）是如何连接的？以 add $t0,$t1,$t2 为例说明一条指令流经哪些部件。

中级简答题后端开发工程师硬件工程师数据通路CPU单周期

题目

考察取指与各执行阶段在部件间的流向。

参考答案

结论

单周期 CPU 把所有部件（PC、指令存储器、寄存器堆、ALU、数据存储器）用总线/连线固定连成一条数据通路，每条指令都在一个完整时钟周期内走完「取指→译码→执行→写回」。

add $t0,$t1,$t2 的流向

  1. 取指：PC 送指令存储器 IM，取出指令；同时 PC+4 指向下一条。
  2. 译码：指令中的 rs=$t1、rt=$t2 作为寄存器堆的读地址，读出两操作数。
  3. 执行：两操作数进入 ALU 做加法运算。
  4. 写回：ALU 结果写回寄存器堆的 rd=$t0。

单周期的代价

所有指令都按「最慢那条指令」定周期长度（例如访存指令最慢），导致大量简单指令在一个长周期里大半时间空闲，硬件利用率低。这也是后来演进为多周期和流水线的原因。

数据通路分两类信号：数据信号（在部件间流动的真实数据）与控制信号（ALU 操作选择、寄存器写使能、存储器读/写等，由控制单元根据 opcode 产生）。
