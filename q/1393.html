海明码（Hamming Code）如何安排校验位与数据位？对 4 位数据 1011 编码，并说明如何定位单比特错误。

高级计算题后端开发工程师硬件工程师海明码纠错校验位

题目

考察校验位位置、覆盖关系与单错定位（syndrome）。

参考答案

结论

海明码把校验位放在 2^k 的位置（1,2,4,8…），每个校验位负责一组「其位置二进制表示中第 k 位为 1」的数据位，形成偶（或奇）校验，从而能定位并纠正 1 位错误。

4 位数据 D=1011（位 3,5,6,7）的编码（偶校验）

位置安排：位1=P1，位2=P2，位3=D3=1，位4=P4，位5=D5=0，位6=D6=1，位7=D7=1。

  • P1（位1） 覆盖位 {1,3,5,7} → 数据位 D3,D5,D7 = 1,0,1 → 偶校验得 P1=0。
  • P2（位2） 覆盖位 {2,3,6,7} → D3,D6,D7 = 1,1,1 → 偶校验得 P2=1。
  • P4（位4） 覆盖位 {4,5,6,7} → D5,D6,D7 = 0,1,1 → 偶校验得 P4=0。

编码后位序 P1 P2 D3 P4 D5 D6 D7 = 0 1 1 0 0 1 1 → 即 0110011。

单错定位

收到码后，按三条校验分组各自重新计算奇/偶，把出错的组号按位拼成二进制，直接得到错误位号，取反即可纠正（ syndrome 非 0 即有错，0 表示无错）。

若要检测 2 位错，需再增加 1 个全局奇偶校验位（SEC-DED，服务器内存常用）。
