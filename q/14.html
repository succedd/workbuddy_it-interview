Python 中深拷贝与浅拷贝的区别？

初级简答题Python后端工程师拷贝Python

题目

说明 copy.copy 与 copy.deepcopy，并用可变对象嵌套举例。

参考答案

  • 赋值 b = a：b 与 a 指向同一对象。
  • 浅拷贝 copy.copy：创建新容器，但内部元素仍是原对象的引用（嵌套可变对象共享）。
  • 深拷贝 copy.deepcopy：递归复制所有层级，完全独立。
import copy
a = [[1,2],3]
b = copy.copy(a)     # b[0] 与 a[0] 是同一列表
c = copy.deepcopy(a) # 完全独立
b[0][0] = 9          # a 也会变
c[0][0] = 0          # a 不变

注意：深拷贝会处理循环引用，但对打开了的文件句柄等不可 pickle 的对象需自定义 __deepcopy__。
