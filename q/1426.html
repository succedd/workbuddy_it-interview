关于 Java 中的 == 与 equals()，下列哪种说法是正确的？ A. 对于基本数据类型，== 比较的是值；对于引用类型，== 比较的是对象的内存地址（是否同一个对象） B. Object 类默认的 equals() 比较的是两个对象的内容而非地址 C. String 类没有重写 equals()，因此 String 的 equals() 也是比较地址 D. 只要两个字符串的字面量相同，用 == 比较就必然返回 true

初级单选题Java后端工程师Java==equals引用类型基本类型

题目

考察点：== 与 equals 的语义差异，以及 Object/String 的默认行为，是 Java 基础的第一道分水岭题，用单选题快速确认。

参考答案

要点：

  • 正确答案：A。== 对基本类型比较「值」是否相等；对引用类型比较「引用（内存地址）」是否指向同一个对象，与内容无关。
  • B 错误：Object.equals() 的默认实现就是 return (this == obj)，即比较地址；只有子类重写后才可能比较内容。
  • C 错误：String 已经重写了 equals()，改为按字符序列逐个比较「内容」是否相同，所以两个内容相同的不同 String 对象 equals 返回 true。
  • D 错误：字面量相同的字符串可能因来自不同创建方式（如 new String）而并非同一对象，== 比较地址会返回 false；比较内容必须用 equals()。
  • 记忆点：== 比地址（基本类型比值），equals 默认比地址、String 已改成比内容。
