Webpack HMR 热更新的原理是什么？

高级简答题前端开发工程师WebpackHMR热更新

题目

描述从文件变化到界面无刷新更新的完整链路，以及为什么状态能保留。

参考答案

链路：① watch 检测到文件变化，增量重新编译该模块，生成 hash 标识的补丁 manifest 与更新 chunk，保留在内存（不写盘）；② dev-server 通过 WebSocket 推送新 hash 给浏览器；③ 客户端 HMR runtime 发起请求拿 manifest，对比后按需拉取更新模块；④ module.hot.accept 注册的回调处理新模块：删除旧模块缓存 → 执行新模块代码 → 沿引用向上传播；⑤ 若向上传播到入口都没人 accept，就退化为 liveReload 整页刷新。

状态保留：因为只替换了模块代码、不刷新页面——组件实例、Vuex store、表单输入都还在内存里。框架 loader（vue-loader/react-refresh）内置了 accept 逻辑，把重渲染包装好，所以业务代码通常感知不到。

注意：样式文件 HMR 只是替换 style 标签，成本最低；改 webpack 配置/入口依赖结构仍需整页刷新。
