从 Webpack 迁移到 Vite 的主要坑有哪些？

中级场景题前端开发工程师Vite迁移工程化

题目

结合实操列迁移中的典型问题与解法。

参考答案

高频坑：① CJS 依赖：只提供 CommonJS 的包会报「无法预优化」，需加入 optimizeDeps.include 让 esbuild 预转换；② global/Node API：浏览器缺 process/global/Buffer，用 define 注入或 polyfill；③ 环境变量：webpack.DefinePlugin 换成 import.meta.env，自定义前缀 VITE_；④ require 上下文：require.context 改 import.meta.glob；⑤ 路径别名/后缀：确认 resolve.alias 与 extensions 一致，.vue 后缀显式补全；⑥ 懒加载语法：动态 import 里的模板字符串要用 import.meta.glob 预先枚举（Vite 无法运行时拼接 URL）；⑦ 插件替换：HtmlWebpackPlugin→vite-plugin-html、MiniCssExtract 内置 CSS 处理；⑧ 老浏览器：需 @vitejs/plugin-legacy 生成 nomodule 兜底。建议先在非核心项目试点，CI 里加产物对比。
