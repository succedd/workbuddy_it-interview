Android 常见的内存泄漏场景有哪些？如何用 LeakCanary 排查？

中级简答题Android开发工程师Android内存泄漏LeakCanary

题目

列举 5 类高频泄漏，并说明 LeakCanary 的引用链报告怎么读。

参考答案

高频场景：① 静态变量持有 Activity/Context（单例构造传 Activity，应传 Application Context）；② 非静态内部类（Handler/AsyncTask/Thread）隐式持有外部 Activity，延时消息期间 Activity 无法回收——改静态类 + WeakReference；③ 未注销的监听/广播/EventBus/协程——onDestroy 里对应 unregister/cancel；④ 属性动画/Handler 延时消息未 cancel；⑤ WebView 持有 Activity（独立进程或手动 destroy + remove 引用）。

LeakCanary 排查：debug 依赖集成后全自动——Activity/Fragment/ViewModel 销毁后仍被引用即触发 heap dump，通知栏给出泄漏报告。读法：看 Reference Chain（引用链）：从泄漏对象逐层列出 GC Roots 路径，标出的红色行是「你该断开的那一跳」——通常是某个静态字段/内部类 this$0；再判断是「真泄漏」还是「故意常驻」（如 Application 级缓存）。修复后重跑验证泄漏计数归零。
