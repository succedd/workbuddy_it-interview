如何用 Python/NumPy 手写 Scaled Dot-Product Attention 的前向计算，并正确处理变长序列的 padding 与因果掩码？

中级编程题算法工程师机器学习工程师自然语言处理工程师NLP后端开发工程师AttentionNumPy掩码Transformer实现

题目

考察点：把注意力公式落地的工程能力，以及变长序列下 padding 掩码（含因果掩码）对 softmax 的影响。

参考答案

要点：

  • 核心公式：Attention(Q,K,V)=softmax(QKᵀ/√d_k)V。先算 QKᵀ 得到注意力分数矩阵，除以 √d_k 做缩放防止点积过大导致 softmax 梯度消失，再对最后一维做 softmax 得到注意力权重，最后与 V 相乘聚合。
  • padding 掩码：变长序列用 0 补齐后，必须在 softmax 前把这些位置的分数为 -inf（或加一个极大负数），否则补齐位会参与加权、污染结果。因果掩码（decoder 用）则是上三角置 -inf，保证第 i 个位置只能看到 ≤i 的位置。
  • 下面给出可运行的 NumPy 实现，注意 softmax 先做数值稳定（减最大值），再与掩码结合：
import numpy as np

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.transpose(-1, -2) / np.sqrt(d_k)   # (..., Lq, Lk)
    if mask is not None:                              # mask 中需要屏蔽处为 0
        scores = np.where(mask[..., None, :] == 0, -1e9, scores)
    scores -= scores.max(axis=-1, keepdims=True)       # 数值稳定
    w = np.exp(scores); w /= w.sum(axis=-1, keepdims=True)
    return w @ V

L = 4
causal = np.tril(np.ones((L, L)))                      # 下三角可见（因果掩码）
print(scaled_dot_product_attention(np.random.randn(1, L, 8),
      np.random.randn(1, L, 8), np.random.randn(1, L, 8), mask=causal).shape)
  • 工程注意：真实训练用矩阵批量、避免显式 -inf（用 additive masking）；推理时常用 KV Cache 避免重复计算历史 Key/Value；长度很大时直接用稠密矩阵会 O(n²)，需 FlashAttention 等稀疏/分块实现。
