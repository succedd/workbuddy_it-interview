中级故障排查题算法工程师后端开发工程师推荐系统故障排查偏差特征穿越

题目

考察对推荐系统线上问题的排障思路，涉及数据质量、特征穿越、曝光偏差等。

参考答案

要点：

  • 先定位是不是真的「模型 / 策略」问题：确认是不是流量结构变化（节假日、新渠道、大盘波动）、前端埋点 / 上报丢失、推荐位曝光入口改动等外部因素——这类往往占多数。
  • 样本与特征侧：检查是否存在特征穿越（训练用了推理时拿不到的未来特征，如把「点击」作为特征）、特征 / ID 映射漂移、实时特征管道断流、线上线下特征不一致（training-serving skew）。
  • 偏差问题：曝光偏差 / 选择偏差——训练只看到曝光过的样本，未曝光 item 被视为负例会误导；可用负采样纠偏或 IPS（逆倾向加权）缓解。也要排查流行度偏差导致长尾被压制。
  • 模型与评估侧：回看离线 AUC / GAUC 是否同步下跌；排查最近一次模型 / 词典 / 配置上线；用留存回放 / 在线 A/B 隔离变量。最终用「先止血（回滚 / 降级到基线）后归因」的节奏处理。
