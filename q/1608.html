推荐系统的冷启动分为哪几类？分别有哪些落地应对策略？

初级简答题算法工程师后端开发工程师推荐系统冷启动

题目

考察冷启动这一经典短板的系统化应对（与首题呼应成链）。

参考答案

要点：

  • 用户冷启动（新用户无行为）：用注册信息 / 设备 / 地域 / 渠道等画像 side info 做泛化召回；热门 / 优质内容兜底；主动试探（EE 探索）快速积累行为；利用跨域 / 社交关系迁移。
  • 物品冷启动（新物品无交互）：基于内容特征（标签、类目、文本 / 图像向量）做内容相似召回；强插 / 提权给新物品曝光机会；用 Look-alike 找相似老用户；冷启动专属模型逐步接替。
  • 系统冷启动（全新平台无数据）：依赖专家规则 / 热门榜单、第三方数据、内容运营编辑，先用内容 / 知识图谱驱动，再随行为积累切到协同 / 模型。
