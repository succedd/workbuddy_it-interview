Spring MVC 如何做参数绑定与数据校验？@RequestParam、@RequestBody、@Valid、全局异常处理分别怎么用？

中级场景题Java后端工程师后端开发工程师Spring MVC参数绑定校验异常处理

题目

考察常用注解与校验 / 异常处理（场景）。

参考答案

要点：

  • 参数绑定：@RequestParam 取 URL query / 表单字段；@PathVariable 取路径变量；@RequestBody 用 HttpMessageConverter 把请求体（如 JSON）反序列化为对象；@ModelAttribute 绑定表单到对象。
  • 数据校验：在入参对象上用 jakarta.validation 注解（@NotNull/@Size/@Pattern 等），配合 @Valid / @Validated 触发校验，校验失败抛 MethodArgumentNotValidException。
  • 全局异常处理：用 @ControllerAdvice + @ExceptionHandler 统一拦截异常，返回结构化错误响应，避免到处 try-catch；也可实现 ResponseEntityExceptionHandler 覆盖 Spring 内置异常（如 404 / 400）。
  • 注意：@RequestBody 校验需 @Valid 标注；日期 / 枚举等类型转换失败会抛 TypeMismatch，应统一捕获返回友好错误信息。
