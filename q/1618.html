Spring MVC 接口分别返回 404、400、415，通常是什么原因？如何排查？

中级故障排查题Java后端工程师后端开发工程师Spring MVC排错HTTP状态码

题目

考察常见 HTTP 状态码根因（故障排查）。

参考答案

要点：

  • 404 Not Found：路径不对——@RequestMapping 的 URL 与方法 / 请求方式（GET / POST）不匹配；Controller 未被扫描（组件扫描包路径没覆盖、少了 @Controller）；上下文路径（context-path）或 DispatcherServlet 的 url-pattern 配置错。排查：看启动日志是否注册了该映射、用相同 method + path 测。
  • 400 Bad Request：参数绑定 / 类型转换失败（如字符串转数字、日期格式不符）、必填参数缺失被校验拒绝、JSON 结构不匹配实体字段。
  • 415 Unsupported Media Type：请求的 Content-Type 与消费端不匹配——如发 JSON 却没带 application/json，或 Controller 用 @PostMapping(consumes="application/json") 但请求体不是 JSON，且缺少对应 HttpMessageConverter（如未引入 Jackson）。
  • 通用思路：开 Spring MVC 的 debug 日志 / 看异常栈，确认是映射、绑定还是消息转换哪一层出错。
