Spring MVC 如何设计 RESTful 接口与统一响应？跨域（CORS）请求为什么要预检（OPTIONS），如何处理？

高级简答题Java后端工程师后端开发工程师Spring MVCRESTfulCORS统一响应

题目

高级，考察 REST 规范与跨域。

参考答案

要点：

  • RESTful 设计：用 HTTP 动词表达语义（GET 查 / POST 增 / PUT 改 / PATCH 局部改 / DELETE 删），资源用名词复数 URI（/users/{id}），状态码表达结果（200 / 201 / 204 / 400 / 401 / 403 / 404 / 500）。用 @RestController（@Controller+@ResponseBody）直接返回数据。
  • 统一响应：定义统一返回体（如 {code,msg,data}），通过 @ControllerAdvice 把成功 / 异常都包成该结构，前端无需逐接口判错；分页 / 错误码规范一致。
  • CORS 预检：浏览器对非简单请求（带自定义头、非 GET / POST 或特殊 Content-Type）先发 OPTIONS 预检，问服务器是否允许该跨域；服务器回 Access-Control-Allow-Origin/Methods/Headers 后才发真实请求。
  • 处理：Spring 用 @CrossOrigin 或全局 WebMvcConfigurer.addCorsMappings 配置允许的来源 / 方法 / 头，并正确处理 OPTIONS；注意**携带凭据（cookie）时 Allow-Origin 不能是 *，须显式来源。
