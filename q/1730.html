NFT 的 tokenURI 与元数据该存哪里？链上、IPFS、Arweave 各有什么取舍？

中级简答题智能合约开发工程师Web3开发工程师NFTtokenURIIPFSArweave

题目

考察 NFT 元数据持久性、成本与可变性。

参考答案

要点：

  • tokenURI 返回什么：通常是一段 JSON，包含 name、image、attributes 等；合约保存 baseURI 或逐 token 的 URI，市场按 URI 拉取元数据。
  • 存储方案对比：链上 data: URI 最永久但最贵，适合小图/纯文本；IPFS 内容寻址、便宜，但需要 pin 服务持续托管，否则可能丢失；Arweave 一次付费、长期存储，适合图片与元数据；中心化 HTTPS 最便宜但可改、可下线，违背 NFT 的不可篡改预期。
  • 实践：图片与 JSON 上 IPFS/Arweave，合约存不可变 URI 或提供冻结开关；注意 gateway 可用性、元数据更新权限与「同一 CID 内容不可变」的验证。
