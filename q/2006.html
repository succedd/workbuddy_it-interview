Dart 中 final 与 const 的区别是什么？为什么 Flutter 中大量推荐用 const 构造？

中级简答题移动端开发工程师Flutter开发工程师全栈开发工程师DartfinalconstFlutter优化

题目

简答题：考察 Dart 常量的两种语义及其在 Flutter 性能上的意义。

参考答案

要点：

  • final：表示「运行期只赋值一次、之后不可变」，值在运行时确定（可以依赖运行时计算的结果，如 final x = DateTime.now()）。
  • const：表示「编译期常量」，值在编译期就完全确定，且 const 变量指向的对象是不可变的（深度不可变）。const 还能修饰构造（const MyWidget()），声明该 Widget 实例是编译期可固化的。
  • Flutter 用 const 的好处：当父 Widget rebuild 时，若子 Widget 是 const，Flutter 能直接复用旧实例（相同 const 构造产生 identical 的同一对象），跳过其 build 与重建，显著减少不必要的重绘开销。
  • 注意点：const 构造要求所有字段都是 final、且构造过程不依赖运行时值；只有真正「不变」的 UI 片段才适合标 const，否则反而会限制动态更新。

记忆法：final = 运行期一次性赋值；const = 编译期固化 + 可被框架复用。Flutter 里善用 const 是「零成本重建」的关键优化手段。
