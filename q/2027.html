题目

用 Filebeat 采集 Nginx 访问日志并写入 Elasticsearch，请给出最小可运行的 filebeat.yml 关键配置。

参考答案

要点：

  • 核心三段：filebeat.inputs（采集哪些日志文件）、output.elasticsearch（发往哪）、setup.kibana（可选，用于一键初始化仪表盘）。
  • 最小配置示例：
filebeat.inputs:
  - type: filestream
    id: nginx-access
    paths:
      - /var/log/nginx/access.log

output.elasticsearch:
  hosts: ["http://localhost:9200"]
  # 可选：username/password 或 api_key

# setup.kibana: { host: "http://localhost:5601" }
  • 说明：filestream 是 7.x+ 推荐输入类型，能断点续传（记录读取偏移，重启不重采）；Filebeat 会把每行日志作为一个 document 写入 ES 默认索引 filebeat-<版本>-YYYY.MM.DD，字段含 message 原文。

补充：若日志需要结构化（如拆出 ip/status/url），可在 ES 侧配 Ingest Pipeline（dissect/grok processor），或在 Filebeat 用 processors 做轻量解析，避免把所有解析压力都压到 Logstash。
