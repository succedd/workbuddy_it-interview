题目

比较阿里云、AWS、Azure 的对象存储产品及常见运维场景

参考答案

产品：阿里云 OSS、AWS S3、Azure Blob Storage。

异同：

  • 存储类型：S3 提供 Standard、Intelligent-Tiering、Standard-IA、One Zone-IA、Glacier、Glacier Deep Archive；OSS 提供标准、低频访问、归档、冷归档；Azure Blob 提供 Hot、Cool、Archive。
  • 生命周期管理：三者都支持生命周期规则自动转换存储类型或删除对象；S3 生命周期规则可针对前缀/标签，OSS 针对前缀，Azure 通过规则定义。
  • 访问控制：S3 使用 IAM Policy、Bucket Policy、ACL、预签名 URL；OSS 使用 RAM Policy、Bucket Policy、ACL、临时凭证和签名 URL；Azure Blob 使用 Azure AD RBAC、Shared Access Signature (SAS)、访问策略。
  • API 兼容性：S3 API 已成为事实标准，很多工具兼容；OSS 提供 S3 兼容接口；Azure Blob 使用自己的 REST API。

运维场景：如客户反映 OSS 访问延迟高，可能原因包括地域选择不当、回源 OSS 走公网未走内网、未启用传输加速、图片处理请求过多；可检查 CDN 命中率、Bucket 所在区域与 ECS 是否同地域、是否使用内网 Endpoint。
