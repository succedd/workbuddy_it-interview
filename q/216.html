客户反映网络慢，你怎么排查？

中级简答题软件开发工程师(通用)系统运维工程师全栈开发工程师云计算工程师网络云服务器

参考答案

第一步：确认是哪段网络慢

→ 客户到云服务器？还是云服务器内部之间？

→ 还是服务器访问外部数据库慢？

第二步：基础连通性测试

→ ping：测试延迟和丢包

→ traceroute：找到哪一跳延迟高

第三步：带宽测试

→ 看云控制台：带宽是否打满（监控图表）

→ 用 iperf3 测试实际带宽

第四步：常见原因和处理

→ 带宽打满 → 建议客户升级带宽/加CDN

→ 某一跳丢包 → 网络链路问题，上报网络团队

→ 服务器内部应用响应慢 → 不是网络问题，是应用问题

→ DNS解析慢 → 检查DNS配置
