浏览器从输入 URL 到页面展示发生了什么？

中级简答题前端开发工程师Web全栈工程师浏览器渲染性能

题目

描述关键步骤：DNS、TCP、HTTP、渲染。

参考答案

  1. URL 解析与缓存检查（强缓存命中直接返回）。
  2. DNS 解析：域名→IP（递归+迭代查询，含 hosts、本地缓存）。
  3. TCP 连接：三次握手（HTTPS 还有 TLS 握手）。
  4. 发送 HTTP 请求，服务器响应（状态码、HTML）。
  5. 解析渲染：构建 DOM 树、CSSOM 树→渲染树→布局（Layout）→绘制（Paint）→合成（Composite）。
  6. 加载子资源（JS/CSS/图片），JS 可能阻塞解析（defer/async 优化）。

期间涉及回流（Reflow）与重绘（Repaint），应减少强制同步布局。
