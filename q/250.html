Android 中 Activity 的生命周期回调有哪些？各自代表什么？

题目

Android 中 Activity 的生命周期回调有哪些？各自代表什么？

参考答案

结论

Activity 是 Android 四大组件之一，生命周期由系统通过一组回调管理：

  • onCreate()：Activity 第一次创建时调用，做初始化（setContentView、绑定数据、初始化变量）。
  • onStart()：Activity 即将可见但尚未可交互。
  • onResume()：进入前台、可交互，应用真正“运行中”的状态。
  • onPause()：失去焦点但仍可见（如被弹窗覆盖），应保存临时状态、停止动画。
  • onStop()：完全不可见。
  • onDestroy()：被销毁前调用，释放资源。
  • onRestart()：从停止态重新回到运行态时调用（stop → start 之间）。

典型流转：启动 → onCreate → onStart → onResume；按 Home 键 → onPause → onStop；再回来 → onRestart → onStart → onResume；退出 → onPause → onStop → onDestroy。

注意：系统可能不调用 onDestroy 直接杀进程；临时 UI 状态用 onSaveInstanceState / onRestoreInstanceState 在 onStop 前 / onStart 后保存恢复。
