题目

React Native 的新架构（JSI / Fabric / TurboModules）相比旧 Bridge 解决了什么问题？

参考答案

结论

旧架构通过 Bridge 用 JSON 序列化异步传递 JS 与原生通信，存在序列化开销、只能异步、模块启动时全量加载等问题。新架构（RN 0.76 起默认，0.82 起移除旧 Bridge）引入：

  • JSI（JavaScript Interface）：C++ 层，JS 可直接持有原生对象引用，支持同步调用，无需序列化。
  • Fabric：新渲染系统，基于 JSI，布局可在任意线程同步计算，支持 React 18 并发特性，提升动画与一致性。
  • TurboModules：原生模块按需懒加载（取代启动时全量加载），并通过 Codegen 在编译期生成类型安全的接口。

收益：同步调用（需要时）、更低内存、更快冷启动、构建期类型校验。第三方库若未迁移到 TurboModules/Fabric 已成为采用风险。
