Java 集合框架中 ArrayList 与 LinkedList 的区别？

初级简答题Java开发工程师Java后端工程师集合ArrayListLinkedList

题目

从底层结构、随机访问、插入删除、内存占用等维度对比，并说明各自适用场景。

参考答案

  • 底层：ArrayList 基于动态数组；LinkedList 基于双向链表。
  • 随机访问：ArrayList get(i) 为 O(1)；LinkedList 为 O(n)。
  • 插入删除：ArrayList 在尾部 amortized O(1)，中间/头部需搬移元素 O(n)；LinkedList 已知节点时插入 O(1)，但查找节点仍 O(n)。
  • 内存：LinkedList 每个节点额外存储前后指针，开销更大。

场景：读多写少、需要下标访问 → ArrayList；频繁在头部/中间增删且迭代访问 → LinkedList。实际中 ArrayList 绝大多数情况更优（CPU 缓存友好）。
