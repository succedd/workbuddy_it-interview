Linux “文本三剑客” grep、sed、awk 各自的定位是什么？能举一个典型用法吗？

初级简答题系统运维工程师公有云售后技术支持grepsedawk文本处理

题目

考察点：三者的职责分工——grep 负责“过滤/查找”、sed 负责“流编辑/替换”、awk 负责“按列处理/统计”；是否理解它们常通过管道组合使用。

参考答案

要点：

  • grep：文本搜索过滤器，按正则匹配行并输出。grep -i 'error' app.log 忽略大小写找出所有 error 行；-r 递归目录，-n 显示行号，-v 反选。
  • sed：流编辑器，擅长按行做替换/删除/插入。sed 's/old/new/g' file 全局替换；sed -i 直接改文件；sed -n '10,20p' 打印指定行范围。
  • awk：按列（默认空白分隔，用 $1 $2 ... 取值）处理的编程语言，擅长统计。awk '{print $1}' access.log | sort | uniq -c 可统计首列频次；awk -F: '{print $1}' /etc/passwd 指定冒号分隔符。
  • 组合哲学：三者通过管道串联，各司其职——grep 先筛、sed 再改、awk 最后算，构成 Linux 文本处理的基石。
