Linux 的文件权限模型是怎样的？rwx、数字表示法、chmod/chown 分别怎么用？什么是特殊权限位？

中级简答题系统运维工程师公有云售后技术支持权限chmodchownSUIDSticky

题目

考察点：ugo 三类主体与 rwx 九位权限位；数字法（如 755）换算；chmod 改权限、chown 改属主；特殊权限 SUID/SGID/Sticky bit 的含义与风险。属简答题。

参考答案

要点：

  • 权限结构：每文件对“属主(u)/属组(g)/其他(o)”三类主体各设 r(读4)/w(写2)/x(执行1) 三位，共 9 位；数字法即三位八进制，如 755 = rwxr-xr-x、644 = rw-r--r--。
  • chmod：chmod 755 file 数字赋权；chmod u+x file 符号法只给属主加执行；-R 递归目录。
  • chown：chown user:group file 同时改属主与属组；-R 递归；常需 root 执行。
  • 特殊权限位：

- SUID（4）：放在属主 x 位（如 /usr/bin/passwd 的 -rwsr-xr-x），使执行者临时获得文件属主权限，常用于需要提权的命令——配置不当是提权漏洞来源。

- SGID（2）：目录上设 SGID 后，其下新建文件继承该目录的属组。

- Sticky Bit（1）：如 /tmp 的 drwxrwxrwt，仅文件属主能删自己的文件，他人不能删。

  • 排查提示：ls -l 看到权限串里有 s/t 即为特殊位，安全审计时要重点检查 SUID 程序。
