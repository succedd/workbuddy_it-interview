线上服务器告警“磁盘空间 100%”，如何快速定位是哪个目录/文件占满，并安全地清理腾出空间？

中级故障排查题系统运维工程师公有云售后技术支持磁盘满dfdulsof运维排查

题目

考察点：用 df 看整体占用、du 逐层下钻定位大文件/大目录；识别“已删除但仍被进程占用（未释放）”的假满盘，并用 lsof/truncate 安全处理。属故障排查题。

参考答案

要点：

  • 第一步看整体：df -h 确认是哪块挂载点（如 / 或 /data）满了；-i 顺带看 inode 是否也满（见下一题）。
  • 第二步逐层下钻：du -sh / 2>/dev/null 看根下各目录大小，再对最大的目录递归 du -sh /data/，定位到具体大目录；du -sh * | sort -rh | head 快速排前几名。
  • 第三步找大文件：find /data -type f -size +1G -exec ls -lh {} \; 列出超大文件，确认无用后删除（如旧日志、core dump、备份包）。
  • 陷阱——已删未释放：若 df 显示满但 du 算不出来，多半是有文件被 rm 但仍有进程占用（lsof | grep deleted 可见）。此时空间不会真正释放，需重启对应进程，或用 truncate -s 0 bigfile 清空而非直接删。
  • 安全清理原则：优先清日志/临时文件、保留期外的备份；删除前确认文件无进程占用、做好备份，避免误删系统关键文件。
