请解释 JavaScript 的原型链（prototype chain）？属性查找是怎样的？__proto__ 和 prototype 有何区别？

中级场景题前端开发工程师原型链prototype__proto__属性查找

题目

考察点：每个对象有隐式原型 __proto__ 指向其构造函数的 prototype；属性沿原型链向上查找；__proto__（实例侧）与 prototype（构造函数侧）的对应关系。属场景题。

参考答案

要点：

  • 原型对象：每个函数（构造函数）都有 prototype 属性，指向一个对象；用 new 创建实例时，实例的隐式原型 __proto__ 会指向构造函数的 prototype。
  • 原型链与属性查找：访问 obj.x 时，先在自身找，找不到就沿 __proto__ 向上（父原型）查找，直至 Object.prototype（顶端为 null），这条链即“原型链”；找到即返回，全程未找到返回 undefined。
  • __proto__ vs prototype：prototype 是构造函数的属性（用来被实例继承的模板）；__proto__ 是实例对象的属性，指向它的原型。即 实例.__proto__ === 构造函数.prototype。
  • 方法共享：挂在 prototype 上的方法被所有实例共享（不占每实例内存），这是 JS 实现“类方法共享”的机制。
  • 现代写法：ES6 class 只是原型继承的语法糖，extends 底层仍是原型链。
