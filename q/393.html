编程题：请手写一个 bind 函数（实现 Function.prototype.bind 的核心功能：绑定 this 与预设参数）。

中级编程题前端开发工程师bind手写this柯里化闭包

题目

考察点：对 this 显式绑定、柯里化（预设参数）、以及 new 调用时 bind 后的函数 this 应指向新实例（new 优先级高于 bind）的综合理解。属编程题。

参考答案

要点：

  • 核心思路：返回一个新函数，调用时用 apply 把固定的 this 和「预设参数 + 调用时参数」传给原函。
  • 简版实现：
  Function.prototype.myBind = function(ctx, ...preset) {
    const self = this;
    return function(...args) {
      return self.apply(ctx, preset.concat(args));
    };
  };
  • 考虑 new 的情况（进阶）：当绑定后的函数被 new 调用时，this 应指向新实例而非 ctx。完整版需用 fBound.prototype = Object.create(self.prototype) 并判断 this instanceof fBound。
  • 考察点拆解：① 保存原函数（this）；② 合并预设参数与运行时参数；③ 用 apply 绑定 this；④ 新调用优先级高于 bind。
  • 为什么考它：手写 bind 能同时验证对 this、闭包、柯里化、原型链的理解，是前端高频手写题。
