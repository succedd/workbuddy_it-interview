编程题：给定正整数数组与一个目标值 s，求「和 ≥ s 的最短连续子数组」长度（LeetCode 209）。

中级编程题算法工程师Java后端工程师滑动窗口子数组前缀和LeetCode209

题目

考察点：滑动窗口在「子数组求和」场景的应用；窗口何时扩张、何时收缩；与前缀和+二分两种解法的对比。属编程题。

参考答案

要点：

  • 滑动窗口法（推荐）：右指针扩张把元素加进窗口和 win；当 win >= s 时记录长度并尝试收缩左指针（减掉 nums[left] 后若仍 >= s 继续缩），直到不满足。每次收缩都更新最小长度。
  def minSubArrayLen(s, nums):
      left = 0
      win = 0
      best = float('inf')
      for right, x in enumerate(nums):
          win += x
          while win >= s:
              best = min(best, right - left + 1)
              win -= nums[left]
              left += 1
      return best if best != float('inf') else 0
  • 复杂度：左右指针各走一遍，时间 O(n)，空间 O(1)。
  • 对比前缀和+二分：先求前缀和 pre，对每个 i 二分找最小的 j 使 pre[j]-pre[i] >= s，时间 O(n log n)；当数组含负数或要查「恰好等于」时二分更通用，但本题全正数下滑动窗口更优。
  • 边界：数组为空或无解返回 0；全正数才能保证“收缩左界仍保持合法性”的单调性。
