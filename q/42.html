缓存穿透、击穿、雪崩是什么？如何应对？

中级简答题Java后端工程师Go后端工程师缓存穿透击穿雪崩

题目

分别解释三者并给出解决方案。

参考答案

  • 穿透：查不存在的数据，缓存与 DB 都没有，请求直击 DB。→ 布隆过滤器、缓存空值（短 TTL）。
  • 击穿：某热点 key 过期瞬间，大量并发同时回源。→ 热点 key 不过期/逻辑过期、互斥锁（只放一个回源）、singleflight。
  • 雪崩：大量 key 同一时间过期，或 Redis 宕机，DB 被打垮。→ 过期时间加随机抖动、多级缓存、Redis 高可用（集群）+ 限流降级、预热。

共同思想：限流、降级、错峰、兜底。
