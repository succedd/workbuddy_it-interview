Java 线程的生命周期有哪几种状态（NEW/RUNNABLE/BLOCKED/WAITING/TIMED_WAITING/TERMINATED）？BLOCKED、WAITING、TIMED_WAITING 三者的触发条件与区别是什么？

初级场景题Java后端工程师线程生命周期线程状态BLOCKEDWAITINGJava并发

题目

考察点：线程状态机、三种『等待』状态的触发（synchronized/Object.wait/await/睡眠）与区别。属场景题（初级）。

参考答案

六种状态（java.lang.Thread.State）

  • NEW：已创建未 start。
  • RUNNABLE：可运行（JVM 把 OS 的『运行中』与『就绪』合一，不细分）。
  • BLOCKED：被 synchronized 阻塞，等监视器锁。
  • WAITING：无限期等待，需被唤醒（Object.wait() 无参 / Thread.join() 无参 / LockSupport.park()）。
  • TIMED_WAITING：带超时的等待（Thread.sleep / wait(timeout) / join(timeout) / parkNanos）。
  • TERMINATED：执行结束。

三者区别

  • BLOCKED：专指等 synchronized 监视器锁，由锁竞争引起，卡在锁上不消耗 CPU。
  • WAITING / TIMED_WAITING：主动调用等待方法让出 CPU，等别的线程显式唤醒（WAITING）或超时自动醒（TIMED_WAITING）；常见于生产者消费者、await/signal。
  • 高频坑：sleep 是 TIMED_WAITING 且不释放锁；wait 是 WAITING 且释放锁。

排查：jstack 里大面积 BLOCKED 多指锁竞争；WAITING/TIMED_WAITING 多指线程在等条件/IO。
