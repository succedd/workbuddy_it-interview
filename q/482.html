Cache 的三种映射方式是什么？各自有什么优缺点？

中级简答题硬件工程师系统软件工程师嵌入式软件工程师Cache计算机组成映射方式

题目

主存块如何放到 Cache 中？请说明直接映射、全相联映射、组相联映射的原理，并对比硬件成本、命中率和冲突缺失。

参考答案

Cache 映射决定“主存块能放到 Cache 的哪些位置”，三种方式：

  1. 直接映射（Direct-Mapped）：主存块 i 只能放到 i mod (Cache行数) 这一行。地址分为 Tag | Index | Offset。
  • 优点：硬件最简单，只需比较一个 Tag，速度快、功耗低。
  • 缺点：冲突缺失（conflict miss）严重，多个映射到同一行的块会互相替换。
  1. 全相联映射（Fully Associative）：主存块可放到任意 Cache 行。地址只有 Tag | Offset。
  • 优点：冲突缺失最少，命中率最高。
  • 缺点：需并行比较所有行的 Tag，硬件成本高、速度慢、功耗大。
  1. 组相联映射（Set-Associative）：Cache 分成若干组（set），组内多行（way）。块映射到固定组，组内任意行。地址为 Tag | SetIndex | Offset，映射公式 Set = i mod (组数)。当每组 1 行即退化为直接映射，1 组即退化为全相联。
  • 折中方案：硬件成本与命中率适中，是实际 CPU 的主流选择（如 8-way、16-way）。

对比小结：

| 方式 | 放置位置 | 硬件成本 | 冲突缺失 |

|---|---|---|---|

| 直接 | 固定一行 | 低 | 高 |

| 全相联 | 任意行 | 高 | 无 |

| 组相联 | 固定组内任意行 | 中 | 低 |
