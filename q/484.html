编程题：将两个升序链表合并为一个新的升序链表（LeetCode 21），要求拼接已有节点、不新建节点。为什么引入哑节点（dummy node）能显著简化代码？ ```python def mergeTwoLists(l1, l2): # 你的实现 ```

初级编程题算法工程师Java后端工程师链表归并哑节点LeetCode21

题目

考察点：有序结构归并 + 哑节点技巧；追问链从单链表操作过渡到双链表协作。追问：如果合并 K 个有序链表，你会怎么扩展？

参考答案

要点：双指针比较取小者接尾，哑节点消除「新头结点」特判。

def mergeTwoLists(l1, l2):
    dummy = ListNode(0)
    tail = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            tail.next, l1 = l1, l1.next
        else:
            tail.next, l2 = l2, l2.next
        tail = tail.next
    tail.next = l1 if l1 else l2  # 直接拼接剩余段
    return dummy.next
  • 哑节点的价值：第一条接上的节点没有前驱，不用 dummy 就得写 if head is None 的特判；有了 dummy，所有节点一视同仁地接到 tail 后面，最后返回 dummy.next，代码少一个分支、少一处出错。
  • 稳定性细节：相等时取 l1（<=）保证归并稳定；循环结束后只需 tail.next = l1 or l2 一次拼上剩余段，因为剩余段本身有序。
  • 复杂度：时间 O(m+n)，空间 O(1)（只动指针）。
  • 扩展：K 个链表可用小顶堆维护 K 个当前头（O(N log K)），或两两分治合并，呼应归并排序结构。
