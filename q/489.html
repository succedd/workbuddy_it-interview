考察点：从具体题上升到题型方法论——识别「两侧最近更小/更大元素」信号，并用哨兵简化边界。追问：为什么最大矩形题要在末尾加一个高度为 0 的哨兵柱？

参考答案

要点：单调栈的通用画像是「对每个元素，求两侧第一个比它小（或大）的元素位置」；84 题把每个柱子当作「决定高度的那根」，用一次遍历同时确定左右边界。

  • 题型识别信号：题目要求与「最近一侧的更大/更小元素」相关——接雨水（42）、每日温度（739）、最大矩形（85 循环调用 84）、移除 K 位数字使最小（402）都共享同一栈形。
  • 84 题模型：对每根柱 i，其能构成的最大矩形宽度 = 右侧第一个更矮柱的位置 − 左侧第一个更矮柱的位置 − 1，高度 = heights[i]。单调递增栈让「弹栈瞬间」恰好同时知道两侧边界：弹出的柱 j，其右侧更矮柱是当前 i，左侧更矮柱是新栈顶。
  • 哨兵作用：在数组末尾追加高度 0（开头也可加 -1），保证所有柱子最终都会被弹出结算，否则遍历结束栈里还剩一段递增序列没算；同时免去「栈是否为空」的特判。这是单调栈题的标准收尾技巧。
def largestRectangleArea(h):
    h = h + [0]           # 右哨兵：强制清栈
    stack, ans = [], 0
    for i, x in enumerate(h):
        while stack and h[stack[-1]] >= x:
            height = h[stack.pop()]
            left = stack[-1] if stack else -1
            ans = max(ans, height * (i - left - 1))
        stack.append(i)
    return ans
  • 复杂度：O(n) 时间、O(n) 空间；暴力双重循环为 O(n²)，在 10⁴ 规模即超时。
