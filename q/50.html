grep / awk / sed 的常见用法？

中级简答题Linux运维工程师DevOps工程师grepawksedShell

题目

各举一个实用例子。

参考答案

  • grep：grep -rn "error" /var/log --include=*.log 递归按关键字查；-v 反选，-i 忽略大小写，-C3 上下文。
  • awk：awk -F',' '{sum+=$3} END{print sum}' data.csv 按列求和；awk '$1>100' access.log 过滤。
  • sed：sed -i 's/old/new/g' file 替换；sed -n '10,20p' 取行；流编辑不改源（去掉 -i）。

三者配合管道是日志分析的利器：cat app.log | grep ERROR | awk '{print $5}' | sort | uniq -c | sort -rn。
