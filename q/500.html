C 语言中 static 关键字的作用是什么？说说它的作用域与生命周期。

初级简答题系统软件工程师C/C++开发工程师嵌入式软件工程师C语言static作用域

题目

请分别说明 static 修饰局部变量、全局变量、函数时的不同表现（作用域、链接属性、生命周期）。

参考答案

static 在 C 中有三类用途，核心影响作用域/链接性与生命周期：

1. 修饰局部变量（函数内）：

  • 作用域：仍在函数内（仅本函数可见）。
  • 生命周期：从程序启动到结束（只初始化一次，存于静态/数据区，不随函数返回销毁）。
  • 效果：函数多次调用间保留值。
void f(){ static int c=0; c++; } // 每次调用 c 递增

2. 修饰全局变量/函数（文件作用域）：

  • 链接属性由外部链接（extern，全程序可见）变为内部链接（internal），仅在定义它的源文件内可见，避免多文件命名冲突。
  • 生命周期仍是整个程序运行期（存于静态区）。
  • 这是 C 实现“模块私有”的主要手段（头文件里声明用 static 或 static inline）。

对比总结：

| 修饰对象 | 作用域 | 生命周期 | 链接 |

|---|---|---|---|

| 局部变量 | 函数内 | 程序全程 | 无 |

| 全局变量 | 文件内 | 程序全程 | 内部 |

| 函数 | 文件内 | 程序全程 | 内部 |
