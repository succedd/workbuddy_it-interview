C 程序的内存是怎么分段的？栈、堆、全局/静态区、常量区各存什么？

中级简答题C语言内存布局栈堆

题目

请描述 C 程序典型内存布局（代码段、数据段、BSS、堆、栈），并说明各区域的生命周期与增长方向。

参考答案

典型进程内存布局（由低地址到高地址常见排列）：

  1. 代码段（Text）：存放可执行机器指令，只读、可共享。
  2. 数据段（Data）：存放已初始化的全局/静态变量（如 int g=10;）。
  3. BSS 段：存放未初始化或初始化为 0 的全局/静态变量，程序加载时由系统清零（不占磁盘空间）。
  4. 堆（Heap）：动态分配区，malloc/free、calloc、realloc 管理；向高地址增长，需手动释放，否则泄漏。
  5. 栈（Stack）：存放局部变量、函数参数、返回地址；向低地址增长，由系统自动分配/回收，遵循 LIFO；容量有限，过深递归会栈溢出。
  6. 常量区/只读数据：字符串字面量（"abc"）等只读常量存放处，修改会导致未定义行为。

生命周期对照：

  • 栈/堆变量：进入/分配时生，退出/free 时灭；
  • 全局/静态（数据段、BSS）：整个程序运行期存在；
  • 代码段：全程只读。

面试要点：栈快但小且自动管理；堆灵活但慢且需手动管理，是内存泄漏与野指针的主要来源。
