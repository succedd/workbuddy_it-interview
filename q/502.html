什么是野指针和内存泄漏？如何避免？

中级编程题系统软件工程师C/C++开发工程师嵌入式软件工程师C语言野指针内存泄漏

题目

请解释野指针的成因（如 free 后未置空、返回局部变量地址、越界）与内存泄漏的成因，并给出防御性编码建议。附带一段示例代码。

参考答案

野指针（Dangling Pointer）：指向已释放或无效内存的指针，解引用会导致未定义行为/崩溃。

常见成因：

  • free(p) 后未将 p 置 NULL，再次使用；
  • 返回函数内局部变量的地址（函数返回后栈帧失效）；
  • 指针越界、数组下标错误。
int *bad(){ int x=5; return &x; } // 返回局部变量地址，野指针！

内存泄漏（Memory Leak）：动态分配的内存（堆）不再使用却未 free，程序持续占用直至结束。长期运行服务会逐渐耗光内存。

常见成因：分配后遗漏 free、提前 return/异常路径跳过 free、指针被覆盖导致原地址丢失。

防御建议：

  1. free(p) 后紧跟 p = NULL;（解引用 NULL 至少可稳定崩溃便于排查）。
  2. 谁分配谁释放，遵循单一所有权；用 valgrind/ASan 检测。
  3. 优先在作用域出口统一释放，避免多出口遗漏（或用 goto cleanup 模式）。
  4. 禁止返回局部变量地址；需要跨函数传递时用 malloc + 调用方释放。
  5. C++ 中优先用智能指针/容器代替裸指针。
