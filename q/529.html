什么是 SQL 窗口函数(window function)？`OVER(... PARTITION BY ... ORDER BY ...)` 如何使用？与 GROUP BY 有何不同？

中级简答题窗口函数OVERPARTITION BYSQL进阶

题目

解释窗口函数的“分组但不聚合 collapsing”语义，给出 ROW_NUMBER/RANK/DENSE_RANK 与 SUM() OVER 示例。

参考答案

  • 窗口函数：对每一行在其所属“窗口（分组）”内计算聚合/排序，但不把多行压缩成一行（与 GROUP BY 不同，后者会折叠行数）。语法：函数() OVER (PARTITION BY 分组列 ORDER BY 排序列 [窗口帧])。
  • 常见函数：

- ROW_NUMBER()：组内连续序号（1,2,3…），并列也唯一。

- RANK()：并列同号、跳过后续号（1,1,3）。

- DENSE_RANK()：并列同号、不跳号（1,1,2）。

- 聚合类 SUM/AVG/COUNT(...) OVER (...)：计算累计/移动值。

  • 与 GROUP BY 区别：GROUP BY 把同组聚成一行；窗口函数保留原行并附加计算列。
  • 示例（各部门按工资排名）：
SELECT dept_id, emp_name, salary,
       RANK() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rk
FROM emp;
  • 示例（累计销售额）：
SELECT order_date, amount,
       SUM(amount) OVER (ORDER BY order_date) AS running_total
FROM orders;
  • 典型用途：取每组 TopN、去重取最新、计算同比/环比、累计求和。
