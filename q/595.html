L1 与 L2 正则化有何区别？为什么 L1 能做特征选择？

中级简答题机器学习正则化L1L2特征选择

题目

请在损失函数中加入惩罚项，解释 L1（Lasso）与 L2（Ridge）正则化的数学形式，并从几何与解的角度说明二者差异及 L1 产生稀疏性的原因。

参考答案

形式（λ 为正则系数）

  • L2（Ridge）：$\min\, J(\theta) + \lambda\sum \theta_j^2$
  • L1（Lasso）：$\min\, J(\theta) + \lambda\sum |\theta_j|$

几何直观（等高线 + 约束区域交点）

  • L2 约束是圆（球），与损失等高线的交点一般不落在坐标轴上 → 权重整体变小但不全为 0。
  • L1 约束是菱形（菱形多面），顶点在坐标轴上；交点极易落在轴上 → 部分权重被精确压缩为 0，产生稀疏解。

为何 L1 能特征选择\n- 绝对值函数在 0 处不可导，次梯度优化会把它推到 0；等价于在最优解处对不重要特征的权重做「截断」。

其他差异

  • L2 更稳定、对共线性鲁棒，L1 在特征多且需降维/可解释时更优；
  • 实践常组合为 Elastic Net（αL1+(1-α)L2）兼顾二者。
