synchronized 与 ReentrantLock 的区别？

中级简答题Java开发工程师Java后端工程师锁并发synchronized

题目

从实现机制、功能特性、性能三方面对比。

参考答案

  • 实现：synchronized 是 JVM 内置关键字（监视器锁），自动加解锁；ReentrantLock 是 JDK 的 API 锁，需手动 lock()/unlock()（推荐 try-finally）。
  • 功能：ReentrantLock 支持可中断（lockInterruptibly）、超时获取、公平锁、多条件 Condition；synchronized 不支持。
  • 性能：早期 synchronized 重量级较慢，JDK6 引入偏向锁/轻量级锁（自旋、锁升级）后两者差距不大；高竞争下 ReentrantLock 更可控。

选型：简单互斥用 synchronized（不易出错）；需要高级特性（公平、超时、可中断）用 ReentrantLock。
