一个 Java 对象从 new 到可以使用，JVM 内部经历了哪几步？对象的访问定位有哪两种方式？

中级简答题计算机视觉工程师CV深度学习工程师目标检测YOLOFasterRCNN

题目

追问链终点。考察点：类加载检查→分配内存→零值初始化→设置对象头→执行 init；分配内存的指针碰撞与空闲列表；并发分配下的 TLAB/CAS；句柄与直接指针两种访问方式。

参考答案

要点一：对象创建的五个步骤

  • 1) 类加载检查：JVM 遇到 new 指令，先检查该指令的参数能否在常量池中定位到一个类的符号引用，并检查该类是否已被加载、解析和初始化；没有则先执行类加载。
  • 2) 分配内存：为新生对象在堆中划分空间，所需大小在类加载完成后即可完全确定。

- 内存规整时用指针碰撞（移动分界指针）；

- 内存不规整时用空闲列表（从列表里找一块足够大的空间）。

- 是否规整取决于垃圾收集器是否带压缩整理功能（Serial/ParNew 规整，CMS 不规整）。

  • 3) 并发安全：分配动作本身要处理并发，做法是 CAS + 失败重试保证原子性，或给每个线程预分配一小块本地线程分配缓冲 TLAB（-XX:+UseTLAB，默认开启）。
  • 4) 零值初始化：把分配到的内存空间（不含对象头）都初始化为零值，保证实例字段不赋初值就能直接使用。
  • 5) 设置对象头 + 执行 <init>()：对象头中写入哈希码、GC 分代年龄、锁状态、类元数据指针等；随后执行构造方法按程序员意愿初始化。

要点二：对象的内存布局

  • 分为三块：对象头（Mark Word + 类型指针，数组还要有长度）、实例数据（父类与子类字段，同宽字段一起分配）、对齐填充（HotSpot 要求对象大小为 8 字节的整数倍）。

要点三：两种访问定位方式

  • 句柄访问：堆中划出句柄池，reference 存句柄地址，句柄里再分别指向对象实例数据（堆）与类型数据（方法区）。

- 优点：对象被移动（GC 复制算法很常见）时只需改句柄中的指针，reference 本身不变，reference 存储地址稳定。

  • 直接指针（HotSpot 采用）：reference 直接存对象地址，对象内存中再保存类型数据的指针。

- 优点：少一次指针定位开销，访问速度更快；由于对象访问在 Java 中极其频繁，这点开销累积起来非常可观。

- 缺点：对象移动时必须修改所有 reference。

要点四：回答要点小结

  • 面试时按「检查 → 分配 → 并发 → 零值 → 对象头 → init」六段答出流程，再补一句 HotSpot 采用直接指针，就完整了。
