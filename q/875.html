Shell 变量赋值与引用有哪些常见坑？为什么变量含空格时 `[ $var = 1 ]` 会报错，正确写法是什么？

初级简答题系统运维工程师Linux运维工程师Shell变量引号单词分割

题目

考察 Shell 变量展开与单词分割（word splitting）机制，以及引用变量的正确姿势。

参考答案

要点：

  • Shell 变量赋值时 = 两侧不能留空格（var = 1 会被当成命令执行）；引用值含空格必须用双引号包住：name="hello world"，否则赋值只取第一段。
  • [ $var = 1 ] 在 $var 为空或含空格时会崩：空变量变成 [ = 1 ]（参数个数不对，语法错），含空格变成 [ hello world = 1 ]（被拆成多个参数）。务必写成 [ "$var" = "1" ]，用双引号包住变量。
  • 推荐用 [[ ... ]]（Bash 关键字）替代 [（外部命令）：它不会做单词分割、支持 &&/|| 和正则 =~，更不易踩坑；数值比较用 (( var == 1 ))。
