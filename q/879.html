Shell 函数只能 `return 0-255` 的状态码，无法返回字符串/多值。如果要从函数「返回」计算结果，有哪些可靠方式？写一个可复用的日志函数示范。

高级场景题系统运维工程师Linux运维工程师Shell函数返回值日志

题目

考察 Shell 函数返回值限制与数据传出模式。

参考答案

传出结果的几种方式：

  • 命令替换：函数把结果 echo 到 stdout，调用方用 result=$(myfunc) 捕获（最常用，干净）。
  • 全局/局部变量：函数内给一个全局变量赋值，调用后直接读取（适合返回多个值）。
  • 子 Shell 陷阱：result=$(func) 中 func 里对全局变量的修改不会传回父 Shell——这是常见坑，多值场景要用全局变量而非命令替换。

可复用日志函数示例：

log() {  # 用法: log INFO "正在备份 $db"
  local level="$1"; shift
  printf '[%s] %s %s\n' "$(date '+%F %T')" "$level" "$*" >&2
}

把日志输出到 stderr（>&2）避免污染 stdout 的数据通道，是函数「既产出日志又不干扰返回值」的标准做法。
