DNS 域名解析的完整过程是什么？递归查询与迭代查询有何区别？

初级简答题网络工程师后端开发工程师网络运维工程师DNS计算机网络域名

题目

请描述从浏览器到权威 DNS 的完整解析链路，并解释递归与迭代、DNS 缓存与常见记录类型。

参考答案

完整链路（以 www.example.com 为例）：

  1. 浏览器 DNS 缓存 → 操作系统缓存（hosts 文件）→ 路由器缓存；
  2. 均未命中，请求本地 DNS 服务器（运营商分配的递归服务器）；
  3. 本地 DNS 依次问：根服务器（返回 .com 顶级域服务器地址）→ 顶级域服务器（返回 example.com 权威服务器地址）→ 权威服务器（返回最终 IP）；
  4. 本地 DNS 缓存结果并返回给客户端。

递归 vs 迭代：客户端→本地 DNS 是递归（你要替我拿到最终答案）；本地 DNS→各级服务器是迭代（每次只告诉我下一步问谁）。

常见记录类型：A（域名→IPv4）、AAAA（IPv6）、CNAME（别名，常用于接入 CDN）、NS（权威服务器）、MX（邮件）、TXT（验证/防垃圾）。

优化：TTL 控制缓存时长；HTTPDNS 绕过运营商劫持；预解析 <link rel="dns-prefetch">。
