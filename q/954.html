let 和 const 相比 var 有哪些核心区别？什么是暂时性死区（TDZ）？

初级简答题前端开发工程师ES6JavaScriptletconstTDZ

题目

考察点：块级作用域、暂时性死区（TDZ）、重复声明、const 的语义（绑定不可变 vs 值不可变）。这是 ES6 变量声明的面试起点题，承接到后续解构/箭头函数中对作用域的正确理解。

参考答案

要点：

  • 块级作用域：let/const 声明的变量只在所在的 {} 块（if / for / 函数 / 任意代码块）内有效；var 是函数作用域（或全局）。典型例子：for (let i...) 每次迭代的 i 是独立绑定，var 会共享同一个 i。
  • 暂时性死区（TDZ）：let/const 在声明语句执行之前处于「死区」，访问会抛 ReferenceError；var 有变量提升且被初始化为 undefined。TDZ 还意味着 typeof 一个尚未声明的 let 变量也会报错（不再是安全的 undefined）。
  • 不可重复声明：同一作用域内不能用 let/const 重复声明同一标识符（var 允许）。
  • const 的语义：const 表示「绑定不可重新赋值」，不代表值不可变——声明对象/数组时其属性、元素仍可修改；如需冻结浅层属性要 Object.freeze（且只浅冻结）。

对比小结：提升阶段 var 初始化为 undefined 可访问；let/const 已进入作用域但不可访问（TDZ）；const 必须在声明时初始化且不能重新赋值。
