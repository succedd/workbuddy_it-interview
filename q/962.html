用递归和非递归（显式栈）分别实现二叉树的前序、中序、后序遍历，并说明非递归写法中节点入栈/出栈的时机。

中级编程题算法工程师Java后端工程师二叉树遍历递归非递归栈

题目

考察点：递归与迭代两种思维、显式栈模拟调用栈、三种遍历在非递归下的差异（尤其后序的经典写法）。

参考答案

要点：

  • 递归本质：三种遍历只差 print(root) 在 traverse(left) / traverse(right) 之间的位置（前：根左右；中：左根右；后：左右根），递归隐式用了调用栈。
  • 非递归前序：根先入栈；循环弹栈 → 访问 → 先把右孩子入栈、再把左孩子入栈（因为栈是后进先出，左后入先出）。
  • 非递归中序：while (root || stack)：先把 root 及其所有左孩子一路压栈，弹栈访问后 root 转向右孩子，再继续压它的左链。
  • 非递归后序：经典写法维护一个 prev 指针判断「上次访问的是左还是右」决定下一步；或更简单的『前序变体（根右左）结果 reverse』技巧。

参考实现（中序非递归）：

function inorder(root) {
  const res = [], stack = [];
  while (root || stack.length) {
    while (root) { stack.push(root); root = root.left; }   // 一路向左
    root = stack.pop();
    res.push(root.val);                                    // 出栈即访问
    root = root.right;                                     // 转向右子树
  }
  return res;
}

复杂度：时间 O(n)，空间 O(h)（h 为树高，链表退化时 O(n)）。
