翻转一棵二叉树（左右子树互换），给出递归实现，并思考能否用层序遍历（非递归）完成？

高级编程题算法工程师Java后端工程师二叉树翻转递归镜像层序

题目

考察点：递归自顶向下翻转、非递归（层序）翻转、边界与『镜像』概念的延伸。这是二叉树操作类的经典追问。

参考答案

要点：

  • 递归（自顶向下）：先递归翻转左子树、再翻转右子树，最后交换当前节点的左右指针；注意要「先拿到左右子树翻转后的结果再交换」，避免边遍历边覆盖导致丢失引用。
  • 非递归（层序）：BFS 遍历每个节点，访问时直接 swap(node.left, node.right)，再把子树入队继续。两种写法本质都是「访问每个节点并交换其左右孩子」。
  • 边界：空节点返回 null；叶子节点无需操作（其左右本为 null）。
  • 延伸：翻转即「整树镜像」，常作为「判断两棵树是否对称/镜像」「判断两棵树是否相同」的铺垫（对称 = 一棵的左镜像等于另一棵的右）。

参考实现（递归）：

function invertTree(root) {
  if (!root) return null;
  const left = invertTree(root.left);
  const right = invertTree(root.right);
  root.left = right;
  root.right = left;
  return root;
}

复杂度：O(n) 时间，递归 O(h) 空间。
