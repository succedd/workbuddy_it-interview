从 Java 8 到 Java 21，语言与 JVM 的演化主线是什么？为什么说虚拟线程是十年来最大的范式转变？

高级开放讨论题Java后端工程师第一性原理必读虚拟线程ZGCProject Loom

题目

考察点：版本节奏变化（半年一版）、模块化、GC 演化（G1→ZGC）、虚拟线程 Project Loom、Valhalla 值类型展望。

参考答案

要点：

  • 四条主线：① 发布节奏：Java 9 起半年一版 + LTS 隔年化，特性以「孵化→预览→转正」三段式渐进落地；② 平台模块化（JPMS，JDK 9）：JDK 自身拆模块 + jlink 裁剪运行时；③ GC 代际更替：G1（JDK 9 默认）→ ZGC/Shenandoah（亚毫秒停顿，大堆服务端）；④ 并发模型：虚拟线程（JDK 21 转正）。
  • 为什么虚拟线程是范式转变：过去十年为绕开「线程贵」，生态全面倒向响应式（Reactor/RxJava），代价是调试栈断裂、代码复杂；虚拟线程让同步阻塞写法天然 scalable，JDBC/Servlet 等阻塞 API 无需重写即可享受——并发模型从「线程池配额」回到「按任务开线程」。
  • 配套落地：结构化并发（StructuredTaskScope）+ 作用域值（ScopedValue）构成新一代并发三件套。
  • 下一站：Valhalla 值类型（扁平化内存布局，减少指针间接）、Panama FFI（替代 JNI）、Amber 语法简化（模式匹配/记录）。

一句话：主线=「让 Java 适配硬件与负载的变迁」：模块化适应云、新 GC 适应大内存、虚拟线程适应高并发 IO——语义稳定、运行时重构。
