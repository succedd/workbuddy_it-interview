Kotlin 相比 Java 有哪些核心优势？为什么 Google 把它定为 Android 首选语言？

初级简答题Android开发工程师KotlinAndroid协程空安全

题目

考察点：空安全、协程、数据类、与 Java 互操作。Kotlin 入门第一题，考察对语言设计动机的理解。

参考答案

要点：

  • 空安全（Null Safety）：类型系统区分 String 与 String?，把 NPE 从运行时错误提前到编译期——这是 Android 崩溃率第一大来源的根治方案。
  • 协程（Coroutines）：suspend 函数用同步写法表达异步逻辑，配合结构化并发（coroutineScope/launch）避免回调地狱与泄漏，取代 RxJava 的大部分场景。
  • 简洁性：data class（自动 equals/hashCode/copy）、顶层函数、扩展函数、类型推导，消除 Java 大量样板代码。
  • 100% 互操作：Kotlin 编译为 JVM 字节码，可与 Java 类无缝互相调用，存量 Android/后端代码可渐进迁移——这是 Google 2019 年定为首选项的现实基础（I/O 大会官宣）。
  • 注意事项：与 Java 混编时注意平台类型（Platform Type）绕过空检查、 companion object 与静态成员的映射差异。
